# Code of Conduct

## Our commitment

QuantumRISC contributors and users should be treated with respect. We expect professional, constructive communication in issues, pull requests, reviews, and discussions.

## Expected behavior

- Be respectful and precise.
- Focus on the code and the engineering problem.
- Give useful, actionable feedback.
- Assume good intent.

## Unacceptable behavior

- Harassment
- Personal attacks
- Spam
- Deliberate misinformation
- Hostile or discriminatory language

## Scope

This applies to repository contributions, issue discussions, code reviews, and any project spaces tied to QuantumRISC.
