# Release Media

This folder contains the public-release media used by the QuantumRISC README and release notes.

## Structure

- `assets/images/` - source engineering images and preserved portal artwork
- `assets/screenshots/` - release preview cards for the website, studio, and docs
- `assets/diagrams/` - SVG architecture diagrams for GitHub rendering
- `assets/demo/` - demo cover art and release demo assets
- `assets/blog/` - article and media references

## Naming

Use descriptive, consistent names:

- `overall-system.svg`
- `backend-architecture.svg`
- `website-hero.svg`
- `studio-dashboard.svg`

Prefer SVG for diagrams and preview cards so GitHub can render them cleanly in the README.
