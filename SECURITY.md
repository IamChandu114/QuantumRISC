# Security Policy

## Supported areas

- FastAPI backend
- Simulation session handling
- WebSocket streaming
- Static asset serving
- RTL and verification assets

## Reporting a vulnerability

If you discover a security issue:

1. Do not open a public issue with exploit details.
2. Report it privately to the repository maintainer.
3. Include reproduction steps, impact, and any relevant logs.

## What to include

- Affected route or module
- Expected vs actual behavior
- Environment details
- Proof of concept if appropriate

## Safe disclosures

If the issue is not sensitive, a normal GitHub issue or discussion is acceptable.
